# Three.js 中东三维地形沙盘

## 目标与已确认方向
参考 UE 制作的中东地形沙盘图，在网页中展示埃及、红海、伊拉克及周边区域。核心陆地应沿地理轮廓抬升，显示卫星地表和山川肌理；周边地图更低、更暗，提供空间参照。支持鼠标拖拽旋转和滚轮缩放。

用户已认可区域地形沙盘方向。最新要求是进一步贴近参考图：不规则陆地厚底、深色周边背景、区域彩色覆盖、信息卡与引线。避免退回全球球体或矩形抬升地块。

## 当前实现
- Three.js + 原生 HTML/CSS/JavaScript，无打包步骤。
- 根据 world.json 国家边界生成地形网格，细分三角形后采样高程。
- 选定中东、北非及周边国家抬升，沿边界补侧壁，替代之前的矩形厚底。
- 低处周边影像压暗，核心地表保持明亮。
- 埃及、伊拉克、阿联酋、巴基斯坦增加透明彩色覆盖与引线卡片；卡片为地理主题说明，没有使用未经核实的油田产量等业务数据。
- 支持拖拽、缩放、自动旋转、国界标注切换、重置视角。

## 数据与资产
- surroundings.jpg：Esri World Imagery 区域影像，范围经度 10–72°、纬度 0–48°，下载尺寸 3000×2400。
- region.jpg：早期核心区域影像，范围经度 24–58°、纬度 12–39°。
- elevation.jpg：来自 turban/webgl-earth 仓库的全球 elev_bump_4k.jpg。当前用灰度采样制作夸张起伏，属于低精度原型；并非经过标定的米制 DEM。
- height.png：早期区域高程裁片。
- world.json：holtzy/D3-graph-gallery 的世界国家边界 GeoJSON。
- earth-color.jpg、earth-normal.jpg、earth-water.jpg：早期全球地球版本遗留素材。
- 地表影像服务：https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer
- 后续正式发布需核查影像和其他数据的使用许可及完整署名要求。

- 最新 app.js 已通过 node --check 语法检查。
- 本地 8877 服务此前验证返回 HTTP 200；这不等于最新视觉效果已验收。

- 原型高程精度不足，边界采样与卫星影像对齐仍需检查。
- 当前按各国家单独生成侧壁，内部国界可能出现不需要的侧壁，应合并核心区域后仅生成外轮廓侧壁。
- 当前透明高亮面没有与地形同等细分，可能与山体交叉或悬空。
- 引线尚需检查虚线距离计算，标签尚无碰撞避让和地形遮挡判断。
- 国家网格统一细分五次，面数偏高，应按空间跨度或屏幕误差自适应细分。
- 未完成在线部署；不要把本地预览地址当作公网地址。

## 后续建议顺序
1. 先在浏览器检查 v5：截图对比参考图，确认卫星影像方向、国家轮廓、山体和侧壁没有错位。
2. 修正影像范围比例：影像服务可能为匹配输出尺寸调整实际范围，应锁定范围比例或读取返回的实际 extent，保证 UV 对齐。
3. 使用可靠的区域 DEM 替换全球灰度图，正确换算高程单位；适度夸张山体而非任意增加噪声。
4. 合并目标国家轮廓并保留海岸线，只给核心区域外边界补厚底；周边也加入较弱地形。
5. 优化倾斜视角、主区域占屏比例、暗色海面、环境遮蔽和边缘阴影，使构图接近参考图。
6. 让彩色覆盖和边界线贴合细分后的地形；修复标签碰撞、引线和移动端布局。
7. 需要业务信息时，再由用户提供油田/项目位置和真实数据。
8. 完成视觉验收后再决定是否部署。
